# 狼人杀·预女猎白标准局 - AI实现文档 (v1.0)

## 1. 元数据与核心常量
- **游戏名称**：狼人杀 (Werewolf)
- **板子代号**：预女猎白 (Seer, Witch, Hunter, Idiot)
- **玩家人数**：12 (固定)
- **胜利条件 (屠边)**：狼人阵营杀光所有**神职 (4)** 或 杀光所有**平民 (4)**；好人阵营放逐所有**狼人 (4)**。

## 2. 角色池定义 (数据结构)
```json
{
  "werewolves": 4,  // 狼人 (互认同伴)
  "villagers": 4,   // 普通村民 (无技能)
  "seer": 1,        // 预言家
  "witch": 1,       // 女巫
  "hunter": 1,      // 猎人
  "idiot": 1        // 白痴 (又称"白神")
}
```

## 3. 技能详细参数 (AI决策用)

### 3.1 预言家 (Seer)
- **唤醒时机**：每晚 (首夜起)
- **行动**：选择一名存活玩家 -> 获取该玩家的 **阵营标签** (Good/Evil)。
- **限制**：无法获知具体角色 (如无法区分女巫与平民)。
- **AI决策权重**：查验优先级为 存疑高位玩家 > 跳神职者 > 划水玩家。

### 3.2 女巫 (Witch)
- **唤醒时机**：每晚 (仅当被狼人刀杀后唤醒，或固定顺序唤醒)
- **解药 (Antidote)**：1瓶。救活当夜被刀目标。**首夜允许自救** (可配置)。
- **毒药 (Poison)**：1瓶。毒杀一名存活玩家。**解药与毒药不可同夜使用**。
- **特殊判定**：若女巫被刀且解药已用，无法自救，直接死亡。
- **AI决策权重**：解药首夜使用率80% (救人)；毒药仅在70%以上确信狼人时使用。

### 3.3 猎人 (Hunter)
- **被动技能**：死亡时可选择**开枪** (带枪出局)。
- **触发条件**：被投票放逐 / 被狼人刀杀 / 被白痴反伤 (若有) -> 可开枪。
- **阻断条件 (枪哑)**：被**女巫毒杀** -> 无法开枪。
- **AI决策权重**：若死亡时未明确锁狼，优先选择"不开枪" (避免误伤)。

### 3.4 白痴 (Idiot)
- **被动技能**：当在**白天投票**环节被放逐时，可**翻牌** (亮明身份) 免死。
- **翻牌后状态**：存活，但**永久失去投票权**。可继续发言，且不受次数限制 (可随时插话)。
- **胜负判定**：在屠边规则下，翻牌后的白痴依然算作**存活神职**。狼人需在翻牌后继续刀杀他才能完成屠神。
- **AI决策权重**：未翻牌前可适度"作死"骗狼刀；翻牌后转为强力逻辑输出位。

## 4. 夜间行动顺序 (严苛顺序)
*此顺序对AI判断"谁在说谎"至关重要：*
1.  **狼人行动**：商议并选定一名击杀目标 (或由系统随机/指定)。
2.  **女巫行动**：获知当夜死讯 (若可救，询问是否使用解药；若解药已用，仅获知死讯)。
3.  **预言家行动**：进行查验。
4.  **守卫 (此板无) / 猎人睁眼** (仅首夜确认身份)。
5.  **白痴睁眼** (仅首夜确认身份)。

## 5. 白天/发言阶段逻辑流

### 5.1 警长竞选 (首日)
- 随机决定顺序。
- 玩家举手 (上警) -> 逆序/顺序发言 -> 退水 -> 未上警玩家投票。
- **警长特权**：1.5票归票权；决定发言方向 (死左/死右/警左/警右)。

### 5.2 发言与放逐
- 存活玩家按顺序发言 (每人单次发言限时)。
- 发言结束后，警长归票，全体投票 (或暗票)。
- 最高票者出局，触发技能 (猎人/白痴)。

## 6. AI 行为树逻辑 (决策生成核心)
*用于指导AI如何做出符合人设的动作：*

| 角色 | 首日 (Day 1) 策略 | 中后期 (Mid-Late) 策略 | 底层逻辑 (底层心态) |
| :--- | :--- | :--- | :--- |
| **预言家** | **必须上警**。报验人，留警徽流 (今晚验谁/明晚验谁)。 | 死亡前尽量给出2-3个金水/查杀。 | 寻找狼人破绽，为好人排坑。 |
| **女巫** | 隐藏身份。若首夜有刀，考虑报银水 (救起的人)。 | 毒药只撒给公认的“铁狼”或自爆的狼人。 | **藏毒**是最强威慑，不乱跳神职。 |
| **猎人** | 可半跳身份 (穿猎人衣服) 威胁狼人不要刀自己。 | 死亡开枪时，优先带走明确逻辑爆炸者。 | 不怕死，但怕毒哑。 |
| **白痴** | 平民打法，潜藏。可故意票型奇葩吸引火力。 | 被推时翻牌自证，之后专注分析。 | 利用“不死”特性干扰狼人刀法。 |
| **狼人** | 悍跳预言家 (报假查杀/金水) 或倒钩 (卖队友)。 | 刀法优先顺序：**明神 (已跳) > 银水 (怕女巫) > 民及民以上**。 | 屠边原则：若场上民少刀民，神少刀神。 |
| **平民** | 站边逻辑，投出认为像狼的玩家。 | 挡刀 (故意穿神职衣服让狼来刀)。 | 唯一武器是**票权**，拒绝划水。 |

## 7. 胜负判定逻辑 (实时检测)
```python
# 伪代码逻辑
def check_winner():
    alive_wolves = count_alive("werewolf")
    alive_good = count_alive("good")
    
    # 狼人胜利 (屠边)
    if alive_wolves == 0: return "Good_Win"
    if count_alive("seer", "witch", "hunter", "idiot") == 0: return "Werewolf_Win"
    if count_alive("villager") == 0: return "Werewolf_Win"
    
    # 平局/特殊 (极少数情况)
    if alive_wolves * 2 >= alive_good: return "Werewolf_Win" # 极致绑票
    return "Game_Continues"
```

## 8. 禁忌与异常处理 (AI陷阱规避)
- **禁止贴脸**：AI不可说出 "我发誓我是预言家" 等场外信息。
- **禁止自爆**：此板子常规局无狼人自爆功能 (除非特别说明)，AI逻辑中应**移除自爆选项**。
- **警徽流失效**：若预言家当夜被刀死，查验结果无效 (死无对证)。
